# Readdy

**A contextual reading and translation platform.**

Readdy is a web application focused on helping readers work with English and French documents through a clean, multilingual reading interface.

## Highlights

- Arabic-friendly right-to-left interface.
- Reading and contextual translation workflow.
- Document processing in the browser.
- OCR support through Tesseract.js.
- PDF support through PDF.js.
- Word document support through Mammoth.js.
- Light and dark themes.

## Run locally

Clone the repository and open `index.html` in a modern browser. Some browser features and external libraries may require a local web server and an internet connection.

## Privacy

Process sensitive documents carefully. Do not publish private documents, credentials, or personal information in this repository.
